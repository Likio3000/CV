Alpha Evolve

How can candidate trading signals be generated and evaluated systematically?

What I built
A Python pipeline for evolutionary search, signal evaluation and backtesting, with a dashboard to run and inspect experiments.
Engineering focus
Separating search from evaluation and making experimental settings and results inspectable.
Evidence to explore
Research documentation, pipeline code, tests and dashboard source. Historical experiments are research results, not a forecast of live performance.

Python · TypeScript · Research pipelines

Data & forecasting

VIC Energy Demand

What can historical energy data tell us about the next day?

What I built
A data preparation and forecasting workflow for Victorian energy demand and prices, with benchmarks and a Streamlit dashboard.
Engineering focus
Chronological train, validation and test splits; aligned next-day targets; checks for gaps and incomplete days.
Evidence to explore
Benchmark scripts, regression tests and the case study. The dashboard currently needs locally prepared datasets; it is not a hosted live forecast.

Python · pandas · Machine learning · Streamlit

Typing Quest

How can typing practice become a clear, progressive learning experience?

What I built
A native macOS typing trainer in SwiftUI, with generated levels, gated progression, session scoring and performance history.
Engineering focus
Keeping session logic and metrics separate from the views, with unit and UI tests for gameplay and navigation.
Evidence to explore
The game core, test suites and a downloadable macOS release. This is a desktop application, not a browser game.

Swift · SwiftUI · macOS

Senda

How can a focus timer stay reliable through pauses, reloads and multiple tabs?

What I built
A React and TypeScript focus app with tasks, progress, English and Spanish, offline reopening and local backups.
Engineering focus
A persisted timer deadline and atomic IndexedDB updates keep sessions consistent across reloads and tabs.
Evidence to explore
The rebuild PR includes source, 44 passing tests and browser validation. It replaces the older Flask app and removes the AI integration.

React · TypeScript · IndexedDB · Vitest
