# Runnable data engineering projects

- [Commerce CDC](commerce-cdc/README.md): incremental warehouse history, independent audit, transactional repair and reproducible write-work evidence.
- [SignalForge](signalforge/README.md): temporal feature joins, explainable coverage gates and recovery of incomplete releases.

Both run with Python 3.12+ and the standard library. Data is synthetic. Read each
project's README for commands, tests, contracts and explicit limitations. These
folders match the source bundles linked from the portfolio; CI checks the hashes.
